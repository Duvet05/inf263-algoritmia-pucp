### 2023-1: Laboratorio 1 — Camiones y caminos de robots

P1 (p. 1): asignación de paquetes a camiones. P2 (p. 3): caminos de robots entre edificios. Ambas preguntas exigen fuerza bruta.

Restricciones del enunciado: El contexto de robots de P2 no implica que el enunciado pida recursión.

### 2024-1: Laboratorio 1 — Kung Fu Panda y radar por anillos

P1 (p. 1): asignación de armas con fuerza bruta. P2 (p. 3): contar unidades detectadas por anillos completos de un radar.

Restricciones del enunciado: P2 exige función recursiva; no admite iterativas anidadas ni variables globales salvo la matriz.

### 2025-1: Laboratorio 1 — Discos y controles de seguridad

P1 (p. 1): asignación óptima de tablas a discos. P2 (p. 2): subconjuntos de controles con presupuesto, dependencias y seguridad mínima.

### 2025-2: Examen 1 — Alertas, Hanói y estructuras lineales

P1 (p. 1): selección de alertas por fuerza bruta. P2 (p. 2): Hanói con movimientos solo entre almacenes adyacentes. P3 (p. 3): intercalar tipos en una lista. P4 (p. 4): rectángulos con pila. P5 (p. 4): cola de prioridad.

Restricciones del enunciado: P2 exige una sola función recursiva y no permite A→C directamente. P4 prohíbe recursión.

### 2025-2: Laboratorio 1 — Controles de seguridad y galerías

Pregunta FuerzaBruta (p. 1): seleccionar controles con restricciones. Pregunta Recursion (p. 2): perforar galerías sin cruzar rocas ni otras galerías.

Restricciones del enunciado: Una sola función recursiva sin iteraciones; se permiten ciclos para cargar datos antes o imprimir después. La solución local usa backtracking.

### 2026-1: Laboratorio 1 — Robot arqueólogo y citas odontológicas

P1 (p. 1): robot arqueólogo que cuenta artefactos y dibuja su despliegue en una matriz. P2 (p. 2): asignar dientes a citas para maximizar ganancias con fuerza bruta.

Restricciones del enunciado: P1 exige una sola función recursiva sin iteraciones; solo se permiten ciclos para imprimir la matriz. No se permiten variables globales.
