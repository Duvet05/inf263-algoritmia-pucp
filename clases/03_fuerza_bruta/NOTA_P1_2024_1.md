# P1 de 2024-1: consigna y código asociado

El enunciado de Kung Fu Panda exige **fuerza bruta**. El archivo [Copia de P1.cpp](../../laboratorios/laboratorio-01/2024-1/material_original/variantes/2024-2/LAB1/Viernes%2013%EF%BC%8F09/Copia%20de%20P1.cpp) combina enumeración de subconjuntos con **backtracking recursivo**:

1. Enumera los `2^N` subconjuntos de armas para un guerrero mediante un cromosoma binario.
2. Descarta los que no cumplen las restricciones y marca las armas de un subconjunto válido.
3. Se llama recursivamente para intentar resolver el siguiente guerrero.
4. Si ese intento falla, desmarca las armas y prueba otro subconjunto.

La recursión es una forma de implementar un algoritmo; la fuerza bruta es una estrategia de búsqueda. Una búsqueda exhaustiva puede ser recursiva. En este archivo hay además validación de asignaciones parciales y retrocesos, por lo que conviene identificarlo como backtracking. La consigna de P1 no dice expresamente que la implementación deba ser iterativa: la sola presencia de recursión no basta para concluir que incumple la evaluación.

## Para plantear una enumeración completamente iterativa

Está disponible [p1.cpp con fuerza bruta iterativa](../../soluciones-actuales/2024_1_lab01_po/2024_1_lab01_p01_po.cpp), junto con [datos1.txt](../../soluciones-actuales/2024_1_lab01_po/datos1.txt) y las [instrucciones para ejecutarlo](../../laboratorios/laboratorio-01/2024-1/material_original/variantes/clase-local/po-iterativo/LEEME.md). Se comprobó con el ejemplo del PDF, casos de restricciones y 30 instancias pequeñas contrastadas con otra enumeración.

Puede usarse un cromosoma en base `G + 1`, donde `G` es la cantidad de guerreros. Cada posición representa un arma: `0` significa no usarla y `1..G` indica a qué guerrero se asigna. Se enumeran las asignaciones completas y se verifican los tipos permitidos, los prerrequisitos en la misma mochila y que el poder supere al del guerrero. Con 3 guerreros y 12 armas hay `4^12 = 16 777 216` asignaciones posibles.

## Problemas observados en el archivo local revisado

- La declaración de `encontrarArmasParaGuerrero` devuelve `bool` (línea 20), pero su definición usa `void` (línea 113) y devuelve valores booleanos. La comprobación con `clang++ -std=c++17 -Wall -Wextra -Wpedantic -fsyntax-only` falla por esta inconsistencia.
- `esCromosomaValido` permite igualar el poder del guerrero, mientras que el enunciado pide superarlo.
