# Mochilas: clase de 60 minutos

[Presentación interactiva](presentacion.html) · [Presentación PDF](presentacion.pdf) · [Práctica](practica.md) · [Práctica PDF](practica.pdf) · [Guion docente](guion-docente.md) · [Guion PDF](guion-docente.pdf)

La sesión explica mochila binaria por fuerza bruta, bases 2 y 3 y Po con tipos y prerrequisitos. El [enunciado original de Po](../../laboratorios/laboratorio-01/2024-1/enunciado.pdf) tiene una ubicación canónica.

El [código de mochila](codigo/mochila_binaria.cpp), los [casos](codigo/casos/) y las [instrucciones](codigo/LEEME.md) sirven para las demostraciones. Po reutiliza [su archivo canónico](../../laboratorios/laboratorio-01/2024-1/material_original/variantes/2024-2/LAB1/Viernes%2013%EF%BC%8F09/Copia%20de%20P1.cpp) y [sus datos](../../laboratorios/laboratorio-01/2024-1/material_original/variantes/2024-2/LAB1/Viernes%2013%EF%BC%8F09/Copia%20de%20datos1.txt).

La presentación funciona sin conexión. Las flechas cambian de diapositiva y F activa pantalla completa. Las [referencias originales](enlaces-de-origen.txt) conservan los enlaces compartidos en Drive y Pásalo.
