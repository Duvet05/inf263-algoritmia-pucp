06 / Código en vivo

La condición que conserva la respuesta.

for (int codigo = 0; codigo < total; codigo++) {
    cargarCromosoma(codigo, n, seleccion);
    long long peso = 0;
    for (int i = 0; i < n; i++)
        if (seleccion[i]) peso += pesos[i];

    if (peso <= capacidad && peso > mejorPeso) {
        mejorPeso = peso;
        for (int i = 0; i < n; i++)
            mejor[i] = seleccion[i];
    }
}

peso <= capacidad

La igualdad sí cabe.

peso > mejorPeso

Solo reemplaza si mejora.

Copia el arreglo

El siguiente candidato cambiará seleccion.

Coste: O(n · 2ⁿ).

12 / La condición que se suele olvidar

El requisito tiene el mismo destino.

Seleccionar un requisito en otra mochila no cumple la regla.

P → Z

P en M2 obliga a Z en M2.

D, I → R

Cada arma seleccionada debe cumplir sus requisitos.

H → Z, E

H es tipo 2.
Z es tipo 3.

H no puede usarse con estos datos: ningún guerrero admite a la vez tipos 2 y 3. Esa conclusión depende de la entrada; no prohíbas H por su nombre en el código.

También K requiere Z. La asignación debe satisfacer todas las dependencias de las armas elegidas.
