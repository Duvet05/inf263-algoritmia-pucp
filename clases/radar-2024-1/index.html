02 Dentro de la recursión

Pila de llamadas

○ Lista para comenzar

Primero, hallarLimites.

Después buscar recorre el borde y reduce sus cuatro límites.

hallarLimites(...); void buscar(..., int &suma) if (filaInicio > filaFin || colInicio > colFin) return; suma += matriz[...][...]; buscar(..., FI+1, FF-1, CI+1, CF-1, suma);

FI/FF = filaInicio/filaFin. CI/CF = colInicio/colFin. Las abreviaturas solo se usan en este resumen; abajo está el archivo completo.

int &suma → 0
1

hallarLimites prepara el cuadrado

Calcula menor y fija filaInicio, filaFin, columnaInicio y columnaFin. buscar empieza por el borde exterior.

2

Los cuatro ciclos suman

Arriba → derecha → abajo → izquierda. Cada celda modifica la misma variable suma. Después los límites se acercan al centro.

3

Los límites se cruzan

Cuando inicio > fin, ya no quedan celdas. Se ejecuta return;. Las llamadas terminan y main imprime la suma acumulada.
