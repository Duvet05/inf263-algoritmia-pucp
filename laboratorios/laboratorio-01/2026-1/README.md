# Laboratorio 1 — Robot arqueólogo y citas odontológicas — 2026-1

Temas: Recursión; Fuerza bruta.

Restricciones: P1 exige una sola función recursiva sin iteraciones; solo se permiten ciclos para imprimir la matriz. No se permiten variables globales.
